What changed, and why

Every control from the current Backtest.jsx is here — filters, sortable headers, scatter axes, equity modes, chart modal, CSV export, day stepper. Same data shape, same API surface; six structural changes on top.

Presets, not a 695-line form

Launching is one chip plus the parameters that actually differ. The other 34 stay behind “Edit parameters”.

was: CompactBacktestForm always expanded above the list

List by default, 17-column table on demand

Runs read as three lines each. The full table is one toggle away and keeps every column, sticky header and audit badge.

was: 17-column table forced into a 760px column

Semantic colour split from the accent

Lavender means selected or primary action. Green, red and amber only ever mean gain, loss and caution.

was: emerald for active tab, gains, and progress

Drawdown shares the equity axis

The overlay is on by default and shares the time axis, so a −17.4% trough lines up with the month that caused it. The legacy flows view is gone — MtM and realized-only cover it.

was: overlay drawn inside the same plot area

Flat stat grid instead of card-per-stat

Five decision numbers get size; the supporting ones get a hairline grid. Border and radius signal hierarchy again.

was: every stat in its own rounded bordered card

Panels stay, collapse buttons go

460px rail, detail takes the rest, stacks under 1200px. Neither panel needs hiding.

was: “◀ Hide left” / “Hide right ▶” buttons
